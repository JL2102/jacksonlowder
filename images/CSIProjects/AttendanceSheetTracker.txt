# WARP.md

This file provides guidance to WARP (warp.dev) when working with code in this repository.

## Project Overview

CSI_AttendanceSheetTracker is a Python utility for processing class schedules and attendance tracking at CSI (a school/training institution). The primary tool is a **Tkinter desktop UI** that lets users select a campus, input PDF attendance sheets, and view extracted class/section/date data in a dark-mode table.

## Development Commands

### Environment Setup
```powershell
# Install dependencies
pip install openpyxl PyMuPDF pillow pytesseract
```

**OCR Setup**: Tesseract OCR is required for scanned/image-based PDFs. Install from https://github.com/UB-Mannheim/tesseract/wiki. The expected path is `C:\Program Files\Tesseract-OCR\tesseract.exe` (configured in `main.py` line 18-19).

### Running the Application
```powershell
# Launch the UI
python main.py

# Run batch PDF section extraction (no UI, campus-folder based)
python OutputSheetSections.py

# Run extraction debug test against TestPDFs/
python Tests/test_extraction.py
```

## Code Architecture

### Main Application — `main.py`
Tkinter desktop app with dark-mode UI. Self-contained — all extraction logic is inlined (no imports from other project files).

**UI features:**
- Campus dropdown selector (Allston, Charlestown, Chicago, Lombard, Skokie, Worcester)
- "Select PDFs" button (file dialog) and "Paste from Clipboard" button (reads files copied in Explorer via PowerShell `Get-Clipboard`)
- "Process" button runs extraction and displays results in a sortable table
- Results table columns: Class ID, Section #, Date, Source File
- Dark-mode theme using ttk `clam` theme with custom palette

**Extraction pipeline (per PDF page):**
1. Try native text extraction via PyMuPDF (`page.get_text()`)
2. If page text is empty or a placeholder ("Pending", "TBD", etc.), fall back to Tesseract OCR at 5× zoom with PSM modes 3, 6, 11 — picks the mode yielding the most section matches
3. Run 11 regex patterns against the text to find section IDs (handles OCR spacing, dash variants, etc.)
4. Clean each match: strip whitespace, normalize en-dash/em-dash/period to hyphen
5. Validate against pattern `^[A-Z]{2,4}\d{3}-\d{1,3}$` and the `VALID_PREFIXES` allowlist
6. Extract session date from `Session #NN - Day, MM/DD/YY` pattern, normalizing 2-digit years
7. Split valid section IDs into Class ID (e.g. `HT111`) and Section # (e.g. `1`)
8. Deduplicate by (class_id, section_num, date) before displaying

**Key constants to update:**
- `VALID_PREFIXES` (line 34-38) — allowlist of course-code prefixes. Currently: AE, AD, ESL, BCM, BCF, BCP, BDM, BFN, BHL, BOA, HCP, NCP, NCW, CSS, DM, BGN, COM, INT, ADV, AEP, MK, BF, HT, BM, ENG, NA. **Add new prefixes here when new course codes appear.**
- `CAMPUSES` (line 32) — list of campus names for the dropdown
- `SECTION_PATTERNS` (line 40-52) — regex patterns for matching section IDs in PDF text

**Dark-mode palette** (line 179-184): BG `#1e1e1e`, BG2 `#2d2d2d`, BG3 `#3d3d3d`, FG `#e0e0e0`, SELECT `#264f78`

### Batch Extractors (no UI)

**`OutputSheetSections.py`** — Processes PDFs in `Input/<Campus>/` folders, writes per-file `.txt` results to `Output/<Campus>/`. Uses 5× OCR zoom with PSM modes 3, 6, 11. Stricter validation with prefix allowlist.

**`OutputSheetSections_working.py`** — Older version. 3× OCR zoom, always uses OCR (skips native text), relaxed validation without prefix allowlist.

**`SectionIDFinder.py`** — Richer extractor that pulls structured table data (Campus, Term, Program, Section, Dates, Schedule, Instructors). Outputs `_sections.txt` files.

**`SingleOutputSheet.py`** — Consolidates all campus PDFs into a single `Output/ConsolidatedAttendanceSheets.txt` report. Groups by campus, sorts by date/section.

**`FillAttendanceSheetTracker.py`** — Auto-filler that reads PDFs, matches sections to rows in the Excel tracker, and writes "Received" into corresponding date columns. Imports from `Test.SingleOutputSheet`.

**`cleanup.py`** — Interactive utility to wipe and rebuild `Input/` and/or `Output/` campus subfolder structure.

### Tests

**`Tests/test_extraction.py`** — Debug script that runs against PDFs in `TestPDFs/`. For each PDF it:
1. Dumps raw page text
2. Shows every regex match with its cleaned form, prefix, and validation status (OK/REJECTED)
3. Runs the full `extract_from_pdf()` pipeline and prints results

Useful for diagnosing why a section ID is not being detected (e.g. missing prefix in allowlist, OCR misread).

## OCR Processing Notes

Both `main.py` and `OutputSheetSections.py` use multiple Tesseract PSM modes (3, 6, 11) and select the result with the most section-ID matches. OCR runs at 5× page zoom for digit accuracy.

Pages with placeholder text ("Pending", "TBD", "N/A") are treated as needing OCR.

Common OCR challenges handled:
- Spacing variations in section IDs (e.g., "AD110- 2" → "AD110-2")
- Different dash characters (hyphen, en dash, em dash, period) all normalized to hyphen
- 11 regex patterns to catch various OCR output formats

## Troubleshooting

**Section not detected?**
1. Run `python Tests/test_extraction.py` with the PDF in `TestPDFs/`
2. Check if the section appears in raw text / regex matches
3. If it shows `REJECTED` with `in_set=False`, add the course prefix to `VALID_PREFIXES` in `main.py`
4. If it doesn't appear in raw text at all, OCR may need tuning (zoom level, PSM modes)
