The Why

A real problem, and someone who mattered

The Problem

My fiancée’s favorite game is Spongebob Monopoly, but her family lives in another state. She wanted a way to keep playing it together — to keep those family bonds strong even across the country.

What I Built

A complete, custom online version of the game — the board, the character pieces, the property deeds, and the rules — built from scratch and hosted on my own site so everyone could join from anywhere.

The Outcome

Her family now plays together online from different states. A store-bought board game became a long-distance family tradition — and I picked up real server and networking skills making it happen.

The Build

A complete custom version, made by hand

Every part of the game is custom-made — the full board layout, the character playing pieces, and the Bikini Bottom property deeds were all assembled by hand and rendered for the web, then wired up to a real-time multiplayer engine.

Hand-Made Assets

Every piece, built for the game

The playable character pieces, each one custom-made for the game.

Under the Hood

What it took to get everyone at the same table

Real-Time Multiplayer

A Python WebSockets server keeps every player’s board in sync in real time — a move on one screen instantly updates everyone else’s, no matter where they are.

Cloudflare Tunnel

I taught myself to expose the game securely through a Cloudflare Tunnel — letting family across the country connect without opening router ports or exposing my home network.

Effortless to Join

A generated QR code lets less-technical family members hop into a game in seconds from their phone — no setup, no installs, no instructions needed.

Custom Game Engine

The board, pieces, and 30+ property deeds were generated and assembled by hand, then driven by a modular JavaScript board engine handling rules, turns, rendering, and game state.

Why this one matters

The project I’m most proud of

This one wasn’t for a grade or a job — it was for someone I love. That made me push to learn things I’d never touched before, and it’s the clearest example of how I work when a problem actually matters:

  • Learned servers & networking by necessity — self-hosting and a Cloudflare Tunnel for secure remote access, picked up specifically to solve this.
  • Built real-time multiplayer from scratch — synchronizing game state across players in different states over WebSockets.
  • Designed a complete custom game — board, pieces, and 30+ property cards, all made by hand.
  • Made it genuinely usable — simple enough that the whole family, technical or not, actually plays it together.
  • Proved the best motivation is real people — the same drive I bring to building software that helps someone.
